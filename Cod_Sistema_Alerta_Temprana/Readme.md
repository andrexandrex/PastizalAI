# Sistema de Alerta Temprana (SAT) para la Degradación de Ecosistemas Altoandinos

Este repositorio documenta un **Sistema de Alerta Temprana (SAT)** enfocado en monitorear la salud y degradación de los pastizales altoandinos.

---

## El Desafío

Los ecosistemas altoandinos, vitales para la biodiversidad y el equilibrio hídrico, enfrentan una presión creciente por amenazas como:

* **Cambio Climático**
* **Sobrepastoreo**
* **Reducción de la Cobertura Vegetal**

La degradación avanza a menudo sin ser detectada a tiempo, lo que dificulta las labores de conservación y manejo sostenible.

---

## ¿Qué Brindamos con este Sistema?

Este SAT transforma datos satelitales (2019-2024) en inteligencia accionable. El objetivo es entregar herramientas claras para:

* **Proteger** áreas críticas de conservación.
* **Priorizar** acciones de manejo y restauración en las zonas de mayor riesgo.
* **Monitorear** la recuperación ecológica y la efectividad de las intervenciones.

A través de mapas de predicción, análisis de tendencias y reportes, el sistema permite a los gestores pasar de una respuesta reactiva a una **gestión proactiva y basada en evidencia**.
