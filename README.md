Descripción
-----------
Proyecto para análisis, diagnóstico y predicción sobre pastizales (p. ej. carbono y cobertura), optimización de modelos y pipelines para potenciales sistemas de alerta temprana.

Estructura del repositorio
--------------------------
- Cod_Diagnostico/  
  Notebooks para limpieza de datos, análisis exploratorio y modelos de predicción (ej.: Prediccion_carbono... , Prediccion_cobertura.ipynb).
- codigo_optimizacion/  
  Scripts y notebooks (o espacio para ellos) para búsqueda y ajuste de hiperparámetros, experimentos y tracking.
- codigos_potenciales_alerta_temprana/  
  Pipelines y notebooks (o espacio para ellos) orientados a detección temprana de anomalías o cambios en series/observaciones espaciales (adicionales)

  Cada uno de los folderes tiene un readme explicando la inicialización y reproducibilidad de cada uno
